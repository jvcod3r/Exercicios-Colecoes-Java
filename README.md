# 📚 Exercícios — Java Collections

Repositório com exercícios práticos sobre as principais estruturas de coleções da linguagem Java, utilizando o pacote `java.util`.

---

## 🎯 Objetivo

Praticar e consolidar o uso das estruturas de dados disponíveis no Java Collections Framework, entendendo o comportamento, as diferenças e os casos de uso de cada uma.

---

## 📁 Arquivos

| Arquivo | Estrutura abordada |
|---|---|
| `Lista.java` | `List` — listas ordenadas com duplicatas (`ArrayList`, `LinkedList`) |
| `Fila.java` | `Queue` — estrutura FIFO, métodos `offer`, `poll`, `peek` |
| `Pilha.java` | `Stack` / `Deque` — estrutura LIFO, métodos `push`, `pop`, `peek` |
| `Hash.java` | `HashSet` / `HashMap` — coleções baseadas em hash, sem ordem garantida |
| `Mapa.java` | `Map` — pares chave-valor com `HashMap`, `LinkedHashMap`, `TreeMap` |
| `ConjuntoBaguncado.java` | `Set` sem ordenação — comportamento de `HashSet` |
| `ConjuntoComportado.java` | `Set` ordenado — comportamento de `TreeSet` ou `LinkedHashSet` |

---

## 🧠 Conceitos Praticados

- Diferença entre `List`, `Set`, `Queue`, `Stack` e `Map`
- Métodos de inserção, remoção e consulta de cada estrutura
- Comportamento de ordenação e duplicatas
- Quando usar cada coleção na prática

---

## 🚀 Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/jvcod3r/Exercicios-Colecoes-Java.git
   ```

2. Compile e execute qualquer arquivo:
   ```bash
   javac Lista.java
   java Lista
   ```

> Necessário ter o **JDK** instalado. Nenhuma dependência externa.
